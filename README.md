# Digital FTE Shared Vault

A shared memory repository and operational vault enabling synchronization between cloud-hosted agents and local AI agents.

## 📂 Vault Structure
- `Company_Handbook.md`: Operational guidelines and guardrails.
- `Business_Goals.md`: High-level objectives and KPI benchmarks.
- `Needs_Action/`: Inbound tasks awaiting agent pickup.
- `Pending_Approval/`: Human-in-the-loop gating for sensitive operations.
- `In_Progress/`: Currently executing agent tasks.
- `Done/`: Archived task artifacts and completion logs.
